# UI spec — Operación diaria

## Principio

La pantalla debe ayudar a una dueña no técnica a responder rápidamente: qué se atendió, qué se cobró, cuánto corresponde a cada profesional y qué dinero hay realmente.

## Referencia actual

`index.html` es la referencia de funcionalidades y flujos: atenciones, cobros, movimientos/cierre, agenda, reportes, profesionales y catálogo.

## Diseño

- Estética premium y cálida: marfil, rosa suave, rosewood, champagne, ciruela profunda.
- Sidebar o navegación persistente; dashboard visual con detalle progresivo.
- Métricas y gráficos solo si aclaran una decisión. Toda cifra agregada debe llevar al detalle.
- Formularios móviles con errores claros y confirmación posterior a guardar.
- No usar rosa Barbie, aspecto genérico de panel administrativo, densidad excesiva ni 3D/WebGL en pantallas operativas.
