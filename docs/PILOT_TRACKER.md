# Seguimiento simple del piloto (2–4 semanas)

## Línea base (antes de comenzar)

Durante tres días anota cómo se trabaja hoy: atenciones reales estimadas, cuántas se registran el mismo día, minutos para cerrar, diferencias pendientes y dudas frecuentes. Es una comparación breve, no un nuevo sistema de analítica.

## Registro diario

| Fecha | Atenciones reales | Ingresadas el mismo día | % mismo día | Minutos de cierre | N.º diferencias pendientes | Monto diferencias | Profesionales revisaron sus datos | Incidentes / dudas / paso confuso |
|---|---:|---:|---:|---:|---:|---:|---|---|
| | | | | | | | Sí / No | |

Calcula `% mismo día = ingresadas el mismo día / atenciones reales × 100`. Anota si una diferencia sigue pendiente, no la ocultes con otro movimiento.

## Revisión semanal

- ¿Se registraron las atenciones antes de cerrar?
- ¿Qué hizo lento o confuso el cierre?
- ¿Las profesionales pudieron ver solo sus atenciones y comisiones?
- ¿Qué incidentes requieren capacitación o corrección?

## Cierre del piloto

Compara el promedio de la línea base con las últimas dos semanas: porcentaje del mismo día, minutos de cierre y diferencias pendientes. Decide si continuar, capacitar nuevamente o detener el piloto hasta resolver un problema concreto.
